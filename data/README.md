# 입력 데이터

최종 실행에는 아래 4개 Excel 파일이 필요합니다. 파일명과 열 이름을 그대로 유지해 이 `data/` 폴더에 넣으세요. Colab에서 원본 셀을 실행할 때는 `/content/`에 업로드합니다. 원본 파일은 저장소에 포함하지 않았으며, `.gitignore`에서 데이터 파일을 제외합니다.

## 최종 알고리즘에 필요한 파일

| 파일 | 필수 열 | 읽는 시트 | 용도 |
| --- | --- | --- | --- |
| `역 경도 위도.xlsx` | `역명`, `위도`, `경도` | `Sheet1` | 역 좌표 목록. 최종 셀에서는 읽어두며, 실제 그래프 좌표는 엣지 파일에서 가져옴 |
| `엣지데이터 신규.xlsx` | `from`, `to`, `from_lon`, `from_lat`, `to_lon`, `to_lat`, `distance` | 첫 번째 시트 | 역명 기반 그래프와 엣지 가중치 |
| `쌍가중치_정규화_OD.xlsx` | `승차_역`, `하차_역`, `쌍_가중치_정규화` | 첫 번째 시트 | 역 쌍의 정규화된 OD 가중치 |
| `총점수_정규화_역주변시설.xlsx` | `역명`, `총점수_정규화` | 첫 번째 시트 | 역 주변 시설의 정규화된 점수 |

- `from`과 `to`는 역명 문자열입니다. 숫자 인덱스를 사용하는 중간 실험용 엣지 파일과 구분해야 합니다.
- 좌표·거리·점수 열에는 유한한 숫자가 필요합니다. 파일 간 역명이 일치해야 하며, 지정한 종착역이 엣지 테이블에 있어야 합니다.
- `distance`는 원본의 경위도 좌표상 유클리드 거리입니다. 미터 단위로 해석하면 안 됩니다.
- 원본은 같은 `(승차_역, 하차_역)` 키가 여러 번 나오면 마지막 행의 점수를 사용합니다. 호선별 중복 자료를 어떻게 합칠지는 별도의 전처리 설계가 필요합니다.
- OD 역명이 비어 있는 행은 원본과 동일하게 제외합니다. 그래프에 없는 역의 OD 행은 경로 점수 합산에 사용되지 않습니다.

## 중간 실험에서 추가로 참조하는 파일

| 파일 | 사용하는 실험 |
| --- | --- |
| `엣지 데이터.csv` | 엣지 데이터를 불러와 연결 예시 확인 |
| `엣지 데이터 그룹화.xlsx` | 그룹화한 역들을 바탕으로 추가 노선 생성 |
| `둔각실험.xlsx` | 둔각 삼각형의 긴 변 제거 실험 |

지도·시설 조회 셀은 Folium 및 OSMnx를 사용합니다. OSM 시설 조회는 인터넷 접근이 필요하며, 현재 OSM 데이터에 따라 결과가 달라집니다. 이 조회는 최종 알고리즘 실행에 필요하지 않습니다.

## 입력 확인

저장소 루트에서 실행합니다.

```bash
python src/optimize_routes.py --data-dir ./data --check-data
```

파일·열·필수 숫자·종착역 존재 여부를 검사합니다. 이 검사는 입력 형식 확인이며, 데이터 전처리의 타당성이나 유효한 노선 후보 생성을 보장하지 않습니다.
